Costo estándar base de instalación

Costo Estándar Base

Este es el costo base de instalación que se aplica a todas las zonas por defecto. Puedes personalizar el costo para zonas específicas en la sección de Disponibilidad de Planes.

Este costo se usará cuando no se especifique un costo personalizado para una zona.

Información

¿Cómo funciona el costo de instalación?

  • El costo estándar base se aplica a todas las zonas por defecto.
  • Puedes personalizar el costo para cada plan en cada zona específica.
  • Si no personalizas el costo, se usará el costo estándar base.
  • El costo final que ve el prospecto es: costo de instalación + precio mensual del plan.
